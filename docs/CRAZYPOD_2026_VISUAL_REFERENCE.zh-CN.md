# CrazyPod 2026 · iPod Classic 概念图适配基线

> 设计评审日期：2026-11-17；依据用户提供的「iPod classic 2025 concept」三机展示截图。本图是**第三方概念设计**，不是苹果官方产品发布、UI 规范或可使用的素材授权。

## 外观与体验方向

- **左图（Home）**：浅蓝白渐变、圆润半透明卡片、有辨识度的彩色音乐图标、轻盈而明晰的文字。真实 320×240 版本保留四项：正在播放、音乐、播客、设置；主屏底部始终保留可用的迷你播放器。不要加入硬件不存在的 App Store。
- **中图（Now Playing）**：以真实专辑封面、歌曲信息、单一进度信息为核心。缺封面时使用宁静的灰褐、蓝灰、鼠尾草等低饱和背景；有封面时以缓存内容主导。仍然使用 Click Wheel 执行导航和播放操作。
- **右图（Controls）**：借用模块化、悬浮式控制中心的美感，不复刻 iOS 无线开关。通过已有的 Home 短按 MENU 操作进入。实际提供播放队列、亮度、音量三项，中央键确认、滚轮调整，MENU 关闭。不显示虚假的 Wi-Fi、蓝牙连接和蜂窝状态。

## 已落实的视觉约束

1. **浅色首页，深色播放**：主页 `#F2F8FF → #BCDDF6`，深色文字 `#202C3C`；Now Playing 保留内容背景和文字遮罩；可见区域之间形成层次，而非所有页面一个黑色主题。
2. **自适应素材**：无封面时使用统一的八色低饱和调色板，避免随机霓虹渐变；有封面时缓存真实艺术图像和背景。
3. **低成本材质**：只使用 LVGL 基础填充/透明度、少量边框、一次性背景缓存；不在硬件滚轮更新周期做高成本实时折射。
4. **真实按钮约束**：每一块卡片都必须被明确焦点选中；不依赖触摸、滑动手势或不存在的硬件。
5. **对比度**：白色玻璃面使用深色文字，背景复杂时叠加亮色保护层，歌词及封面播放信息使用深色保护层。
6. **技术边界**：不触及 Rockbox 底层音频、USB 存储、引导器、升级机制或用户音乐文件。

## 模拟器与真机验收

- 必须检查 320×240 真实渲染截图；概念图不能替代截图。
- 检查 8 种本地化语言（特别是中日韩菜单行的截断）、极亮/极暗自定义壁纸、无封面、带封面、长歌名、Cover Flow、亮度/音量调整。
- Home → Controls → Home、Home → Now Playing → Home 的物理按钮路径需要无误触、无跳焦、无 TE 显示撕裂。
- 完整 ARM 固件与 macOS 模拟器 CI 通过之后，仍需实机验证内存、持续播放、低电量、Hold、USB、安全重启和恢复。任何 CI 成功都**不等于**已通过实机验证。

**品牌定位**：这是一款独立 CrazyPod 固件，设计目标是「仿佛 2026 年发布的新款 iPod」，不冒充苹果正式系统或产品。
