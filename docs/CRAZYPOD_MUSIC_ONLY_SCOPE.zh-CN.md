# CrazyPod 纯音乐播放器 · 产品与移除契约

状态：2026-11-19 起覆盖先前“全功能 App 系统”路线，PR #4 仍为 Draft。

## 产品边界

CrazyPod 应是 iPod Classic 6G/6.5G/7G 上的专用本地音乐播放器，
不是手机式应用启动器、游戏机、电子书阅读器或可安装 App 的通用操作系统。

- 核心任务：浏览音乐库（歌曲、歌手、专辑、列表、搜索、封面）→ 播放 →
  暂停、切歌、快进、随机、循环、调音与管理播放队列。
- 保留原系统音乐文件的兼容读取，包括只读解析经典 iTunesDB；
  读库失败时优先保留文件扫描和解码能力，不写 Apple 原始数据库。
- 保留歌词、收藏、Cover Flow、音量、均衡器、Click Wheel、锁屏、
  亮度、电源、睡眠定时器、USB、存储、状态恢复和必要设置。
- 播客目前作为本地音频兼容入口保留，不能引入独立应用生态。
- 旧版的照片、视频、图书、笔记、联系人、日历、运动、秒表、Mini Apps、
  2048、应用管理器与外部可安装应用不再属于最终产品。
- 可以保留固定的播放页外观选择，但不保留以 Mini App 包为基础的
  任意代码扩展机制；需迁移到原生呈现后再安全卸载依赖。

## 分批移除方案

1. **用户入口（已完成）**：顶层目录只允许 Music、Podcasts、
   Shuffle、Lock、Settings；旧版保存的 17 槽应用顺序只解析保留项；
   来自旧代码的非音乐启动/根路由请求被拒绝。
2. **分发包（已完成）**：固件 ZIP 只新建 Music、Podcasts 目录；
   只打包五个原始 basic BMP；不再把 Mini Apps 的 CPK 安装包复制到
   固件或模拟器设备目录。资源仓库中原始 16 张 BMP 暂保留用于版本追溯。
3. **后台调度（部分完成）**：停止每个 UI tick 对照片、视频、
   图书、笔记、日历、运动与 Mini App 闹钟的轮询；音乐扫描、
   专辑封面、锁屏和状态持久化继续工作。
4. **彻底解绑（未完成）**：从 UI 路由注册、页面渲染、输入调度、
   构建源码列表及其测试和打包工具移除上述非音乐实现。
   旧版可安装 Now Playing 主题仍依赖 Mini Apps 的部分运行时，
   在原生替代建立之前不能盲目删除。
5. **验证（未完成）**：完整 CI（host、iPod 6G 固件、macOS 模拟器）、
   所有目标显示屏类型和实体滚轮的导航/音频/USB/睡眠/恢复回归。

## 数据与发布要求

- 不删除、不迁移、不覆盖设备用户原有的音乐、照片、视频、ROM、
  存档、备忘录、图书或 Apple iTunesDB；只减少新固件提供的功能和
  新生成 ZIP 中附带的非音乐资源。
- 旧状态文件保持 v17 二进制形状；退役应用 ID 不能映射为其他应用，
  读取历史 enabled mask 时必须丢弃已移除功能位。
- 未通过完整构建/模拟器与实体 iPod 验证前，不得宣称纯音乐系统
  已完成或将 Draft PR 作为可安全刷机的正式固件。
- 所有删减以可编译、可测试且不破坏播放的提交推进；入口隐藏不等于
  后台代码和二进制模块已经移除。
