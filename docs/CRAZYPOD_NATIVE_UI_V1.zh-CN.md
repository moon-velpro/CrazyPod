# CrazyPod · Apple-like Native UI v1

> 设计对照：用户已确认的 Home / Music / Now Playing / Controls / Settings 五屏概念稿。基于 Rockbox / LVGL 9.5 / iPod Classic 6G 的 320×240 RGB565 真正固件源代码，不代表已有与概念稿逐像素相同的真机截图。

## 目标

从“卡片很多的自定义播放器皮肤”转为“像 iPhone 的原生音乐/设置界面，同时保留实体 Click Wheel 的 iPod”。设计是风格借鉴，不混淆苹果官方的素材使用权；个人内部图标统一由 `CRAZYPOD_PRIVATE_ICONS_DIR` 提供、正式构建使用原创图标回退。

## 本轮实际修改

| 页面 | LVGL 修改 | 输入 / 性能不变量 |
|---|---|---|
| Home | 接近白色的底色；深色字；四个应用入口仅选中行淡蓝高亮；其余用 1px 分隔线；保留 21px iOS 圆角方形图标 | Click Wheel detent 仍仅刷新前后两行；帧 flush→TE 栅栏、菜单数目和坐标未改 |
| Music 根菜单 | 隐去右侧预览卡片，全宽原生风格列表，大标题、浅底、深色行文字、细分隔线、淡蓝选中态 | 现有六行窗口/索引/预取契约不变；无额外后台读取；不可见的专辑预览不再解码 |
| Settings 根菜单 | 与 Music 同样的全宽浅色列表；不再随机依赖用户调色板的粗线渐变选中态 | 修改的是显示层，不改持久化设置和分类行为 |
| Now Playing | 缩减专辑右侧独立浮起面板感；音频波形压缩为 8px 轨道；保留实时曲目/封面/歌词/进度、加入上一首/播放暂停/下一首视觉状态 | 播放键视觉由已有 audio_status 更新；音频协议、按键物理路由和歌词触发条件不变；不增加触摸控制 |
| Home Mini Player | 原 42px 炫光音频球改为纯播放/暂停状态符号；原玻璃缓存继续用于底座 | 隐藏频繁绘制的圆球波形；保存原暂停控制逻辑，不改变歌曲信息获取和点击区域 |
| Controls | 三列大圆按钮更换为三条纵向圆角设置行，音量/亮度显示当前百分比缩略条；调整页从大转盘改成水平百分比条 | 中键进入调整，旋转调值，使用原背光/音频音量接口；无新的刷新时模糊或滑动触摸输入 |

## 需要继续实机验证

- 320×240 LCD 上 14px 菜单图标、字色和小选中背景在真实色深与背光下是否清晰。
- Home 滚轮选择到画面呈现的 P95 延迟（目标仍为 ≤50ms，未测），快速滚动与 Hold 释放后的缓存一致性。
- 仍通过已有字幕、音频、USB、低电量和锁定行为测试；不得通过改变 LCD TE / I2S / 解码时序来做视觉补偿。
- 当前每个根菜单的 7 个入口使用 **6 行可见滚动窗口**，不是概念图中一次显示 7 行；按现有滚轮导航与内存约束保留。
- 本轮不触及主题数据格式与音频持久化，也没有把用户上传的官方风格图标写回公开 Git 仓库。

## 验证原则

宿主 C99 + 静态契约检查、iPod 6G ARM 固件链接、macOS 模拟器都必须重新通过。历史 macOS CI 曾在 Make 3.81 下报 `firmware/crt0.o` 缺失，不能将 ARM 成功误报为模拟器也成功。PR 保持 Draft；未刷机。概念图不是实机拍照。
