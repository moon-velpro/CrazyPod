## 固件集成方式

1. **只在创建 Home 快捷控制弹窗时采样**：`crazypod_overlay_glass_home_controls_panel()` 捕获已绘制的 320×240 屏幕对应局部区域，复用 `crazypod_image_render_glass_rgb565()`。
2. **缩采样至四分之一宽/高再做两次滑动窗口模糊**：横向/纵向各 5-tap，以 O(W×H) 实现；预先调成 RGB565 浅蓝白材质。
3. **渲染静态玻璃层**：`CRAZYPOD_GLASS_HOME_CONTROLS` 使用高亮边框、细小顶部亮光、底部低饱和蓝边和低透明度阴影。深色旧弹窗仍沿用原有材质，不改变其行为。
4. **弹窗从菜单切换到音量/亮度面板时先清除旧面板并刷新底层**：仅这一场景重新采样，避免把上一弹窗的内容模糊进新面板；快捷控制滚动只改变样式/数值，不重新模糊。
5. **显示/音频安全**：不更改 50fps 帧时钟、LCD TE 同步、Click Wheel 驱动、播放线程、USB、休眠或持久化数据。

## 内存与性能约束

原有弹窗缓存为 `(320-24)×(240-16)×2 = 132,608` 字节的 RGB565 渲染区，加上两个 `74×56×2 = 8,288` 字节的采样/暂存区，合计 **149,184 字节**。本次浅色 Home 材质**复用**这三个已有静态缓冲区，没有再添加同规模的新缓存。两条高光线是少量 LVGL 对象，无运行时折射与逐帧模糊。

注意：每次首次开启或切换控制面板仍会有一次同步 CPU 采样与模糊，可能造成可感知的打开延迟。真机需要测量弹窗打开时间、音频下溢、堆峰值和长时间稳定性；如超出预算，应优先改成在壁纸变更时离线计算，再使用纯色玻璃退化层，而不是强行提高全局 CPU 频率。
